# handoff

작업 전환 시 저장소 경로와 실행 근거를 작업 ID별로 전달한다.

## 입력과 선행 조건

- 작업 ID, Git 상태, 변경 목록, 검증 로그 요약
- 작업 상태와 실패한 접근이 현재 작업에 해당하는지 확인한다.

## 적용 범위와 도구

할당된 프로젝트와 명시적으로 허용된 범위에서만 적용한다. 사용 도구는 Git 읽기, 문서 편집, agent-toolkit handoff다.

## 절차

1. `agent-toolkit handoff create <id>`로 작업 문서를 만들거나 기존 작업 문서를 연다.
2. 현재 목표, 완료 및 진행 중인 작업, 파일, 성공·실패 접근과 테스트 결과를 기록한다.
3. 브랜치·커밋, 남은 문제, 첫 재개 단계 및 관련 경로를 확인한다.

## 출력과 검증

작업 ID별 HANDOFF 기록. 다른 작업자가 문서와 저장소만으로 다음 확인을 재현할 수 있다.

## 실패 처리와 제한

저장할 수 없는 민감 기록은 생략하고 확인할 승인 범위만 남긴다. 프로젝트의 보안 및 승인 정책을 따른다. 선행 Skill 의존성은 없다.
