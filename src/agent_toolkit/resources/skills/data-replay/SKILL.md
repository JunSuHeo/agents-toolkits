# 중단된 작업의 재처리

작업 단위, 중복 판정 키, 결과 저장과 체크포인트 저장 순서를 먼저 그린다. 재시도 가능한 환경과 데이터를 확인하고 검증은 로컬 합성 입력 또는 승인된 사본에서 수행한다.

1. 같은 입력을 처음부터 끝까지 한 번 처리한 결과를 기준으로 보관한다. 행 개수 외에 키별 값과 누적 효과도 비교한다.
2. 결과가 저장된 직후, 진행 위치가 저장되기 직전에 중단된 상태를 만든다. 재개한 결과와 기준을 비교한다. 반대 순서로 기록하는 구현이라면 처리되지 않은 항목을 건너뛸 수 있는 지점을 조사한다.
3. 동일 이벤트의 재전송과 내용이 다른 정정 이벤트가 같은 키를 쓸 수 있는지 확인한다. 외부 알림과 결제 같은 부작용은 대역에서 호출 수와 인자를 관찰한다.

## 예시 — 일별 집계

A(2), B(3) 입력으로 정상 합계는 5다. A를 반영하고 체크포인트 저장 전에 중단한 뒤 재개하여 7이 되면 A가 두 번 더해진 것이다. 이벤트별 반영 여부와 체크포인트를 함께 기록할 수 있는 경계를 찾아 같은 지점에서 다시 검증한다. 실제 운영 재처리는 대상 범위와 승인에 따른다.
