# project-init

새 프로젝트나 기존 저장소에 Toolkit 구성을 결정하고 안전하게 초기화한다.

## 입력과 선행 조건

- 프로젝트 목적, 예상 팀 규모, 기술 스택, 배포 경계와 AI 도구
- 프로젝트 루트 및 쓰기 권한 확인. 기존 저장소는 읽기 조사부터 시작한다.

## 적용 범위와 도구

할당된 프로젝트와 명시적으로 허용된 범위에서만 적용한다. 사용 도구는 읽기, Git 상태, agent-toolkit CLI다.

## 절차

1. 새 프로젝트는 `init --dry-run`, 기존 프로젝트는 `inspect`와 `adopt`로 계획을 본다.
2. Profile, Stack, 도구, 구성 크기와 품질 Gate를 결정한다. 명확하지 않은 스택은 증거를 구한다.
3. 계획을 검토하고 기존 지침 연결 방법과 소유자 파일을 기록한 뒤 적용한다.
4. `agent-toolkit validate`와 `status`로 결과를 확인한다.

## 출력과 검증

구성 선택, 계획, 적용 결과 및 남은 수동 연결 목록. 이전 파일의 해시, 예상 Adapter 경로, 검증 종료 코드를 확인한다.

## 실패 처리와 제한

충돌 파일은 보존하고 선택한 경로, 충돌 원인 및 수동 해결 절차를 보고한다. 프로젝트의 보안 및 승인 정책을 따른다. 선행 Skill 의존성은 없다.
