# Toolkit 개선

1. 프로젝트 이름, 비즈니스 데이터, 키, 원본 대화와 코드 없이 반복 양상과 영향을 기록한다.
2. **Technology Researcher**가 공식 출처를, **Compatibility Manager**가 도구와 형식의 차이를 확인한다.
3. **Skill Manager**는 기존 Skill과 중복을 검토한다. **Agent Optimizer**는 호출 수와 컨텍스트 관련 근거를 비교한다.
4. **Quality Auditor**가 회귀 및 안전성 검증을 수행한다. **Toolkit Maintainer**가 적용 범위와 사용자 승인을 확인한다.
5. **Release Manager**는 검증이 끝난 승인 변경의 버전, 변경 이력과 이전 방법을 준비한다.
