# 작업 협업과 컨텍스트

- **Small** 작업자는 완료 기준을 확인하고 직접 수정·검증한다.
- **Medium** 설계, 구현, 검증을 구분한다. 계약이 바뀌거나 독립 검토가 필요하면 관련 역할을 하나씩 선택한다.
- **Large** 의존성과 변경 경로를 나눈다. 독립 작업만 worktree로 병렬 진행하고 파일 소유자를 지정한다.
- **Critical** 보안, 운영 또는 데이터에 영향을 주는 작업이다. 구현자 외의 검증자와 승인 경계를 명시한 뒤 실행한다.

루트 지침과 해당 작업에 필요한 문서부터 읽는다. Skill은 이름과 설명을 보고 고르고 선택한 절차만 읽는다. 대화 전체 대신 재검증할 수 있는 파일 경로, 결정, 명령, 실패 원인과 작업 ID를 인수인계한다.

작업 전 Git 상태, 브랜치와 기준 커밋을 확인한다. 한 파일에서 병렬 수정이 필요하면 순차 처리한다. 통합 후 전체 변경을 검증한다. Git worktree는 파일 작업 공간을 나누는 기능이다. 권한 및 네트워크 격리는 별도의 실행 환경에서 관리한다.
