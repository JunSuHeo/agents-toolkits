# 품질 및 검증

변경이 실행되는 실제 진입점에서 빌드, 정적 분석, 단위·통합·E2E·회귀 중 필요한 것을 실행한다. 보안, 의존성, 접근성, 성능 및 공개 문서는 해당 경계가 바뀔 경우 확인한다.

기존 테스트의 기대값을 변경하려면 요구사항 근거를 남긴다. 재현 가능한 결함은 수정 전 실패와 수정 후 성공을 비교한다. 필수 검증이 실패하거나 실행할 수 없으면 결과와 남은 조건을 기록한다.

검증 결과에는 환경, 명령, 실제 종료 코드, 기대와 관찰, 미검증 범위, 재현 절차를 포함한다. 독립 검증의 범위와 검증자를 확인한다.
