# 변경 이력

## 0.1.3

- 공통 스킬 9개를 추가하고 기존 10개에 판단 기준과 산출물 예시를 보강했다.
- 표준 구성에 저장소 탐색과 결함 진단을, 확장 구성에 리팩터링과 릴리스 검증을 추가했다. 프로필에 따라 API 호환성, 접근성, 데이터 재처리, 성능 조사, 에이전트 평가를 선택한다.
- 기존 프로젝트는 `update --dry-run`에서 추가될 경로와 본문 변경을 확인할 수 있다. 명시적으로 지정한 스킬 목록과 최소 구성의 선택 규칙은 유지한다.
